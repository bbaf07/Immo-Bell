# Guide de démonstration : 10 minutes

Avant de commencer : lancer le site (`cd web && npm run dev`), ouvrir http://localhost:3000, descendre en bas de page et cliquer sur **Réinitialiser la démo**.

| Minute | Action | À dire |
|---|---|---|
| 0–1 | Page d'accueil, puis « Revoir l'ouverture » en bas de page | Un nom de prestige, une gestion d'excellence : tout Douala, en commençant par Bonanjo. |
| 1–3 | **Biens** → filtrer (Bonanjo, budget 400 000) → ouvrir un bien → **Visite 360°** → simulateur de budget | Le client voit, visite et vérifie qu'il peut payer, sans se déplacer. |
| 3–4 | Ouvrir **Awa** : « Un 3 pièces à Bonanjo sous 400 000 FCFA », puis « Je gagne 450 000 FCFA par mois » | L'assistante cherche, calcule et prépare la réservation. |
| 4–5 | **Mon espace → Client** : tableau de bord, suivi en 6 étapes, pièces manquantes | Le locataire sait où en est son dossier à chaque instant. |
| 5–6 | **Analyste juridique** : file de dossiers, décision avec motif | 72 h pour décider, motif obligatoire, traçabilité. |
| 6–7 | **Propriétaire** : calendrier, relevés, ajout d'un bien | Le bailleur confie ses biens et suit ses revenus. |
| 7–8 | **Prestataire** : urgence dispatchée, « Je suis en route », rapport | Le réseau d'artisans agréés répond aux urgences. |
| 8–10 | **Administrateur** : biens à valider, demandes, urgences, comptes, litiges, rapport, feuille de route V2 | Tout est piloté depuis un seul tableau de bord. |

## Pièges à éviter

- Les profils de démonstration enregistrent leurs actions **dans le navigateur** : utiliser le même navigateur pendant toute la présentation.
- Pour un client qui a déjà une demande sur un bien, le site propose « Suivre ma demande » au lieu de « Réserver » : choisir un autre bien libre pour montrer la réservation.
- Réserver demande d'être connecté : choisir d'abord le profil **Client**.
- Une notification arrive 6 secondes après le choix d'un profil (c'est voulu).
- Si quelque chose semble bloqué : **Réinitialiser la démo**, puis recharger la page.
- Les prix, avis et dossiers affichés sont des exemples ; les tarifs des services et la base de calcul des packs sont encore à confirmer.
