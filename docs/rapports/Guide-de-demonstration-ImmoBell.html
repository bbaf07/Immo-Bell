Guide de démonstration d'Immo Bell

Comment lancer le site, comptes fictifs, données d'exemple et parcours à présenter.

Version du 21 octobre 2026
À utiliser avec le dépôt github.com/bbaf07/Immo-Bell

1. Avant de commencer

Lancer le site (une seule fois)

  1. Installer Node.js 20 ou plus (nodejs.org) et récupérer le projet : git clone https://github.com/bbaf07/Immo-Bell.git.
  2. Dans un terminal : cd Immo-Bell/web, puis npm install (quelques minutes la première fois), puis npm run dev.
  3. Ouvrir http://localhost:3000 dans Chrome ou Edge. Le premier affichage prend environ une minute (compilation). Ne pas fermer le terminal pendant la présentation.
Avant chaque présentation : descendre tout en bas de la page d'accueil et cliquer sur Réinitialiser la démo. Utiliser le même navigateur du début à la fin : les actions sont enregistrées dans le navigateur.

Repères de l'écran

  • En haut à droite : FR / EN (tout le site se traduit), la cloche des notifications, la pause des animations, le soleil/lune (thème clair ou sombre) et le nom du compte connecté.
  • En bas de page : Réinitialiser la démo, Revoir l'ouverture (animation d'introduction), Fiches à imprimer, Mode économie (site allégé pour les connexions lentes).
  • Dans « Mon espace », la bande noire propose « Démo, voir en tant que » : un clic change de profil sans se déconnecter.

2. Comptes fictifs

Il n'y a pas de mot de passe. Pour entrer, aller dans Mon espace et cliquer sur l'une des 5 cartes de profil. Le formulaire « Connexion » par e-mail et mot de passe sert aux vrais comptes et ne fonctionne qu'avec le serveur : ne pas l'utiliser en démonstration. La connexion par téléphone accepte n'importe quel numéro avec le code 123456 (profil « Visiteur mobile »).

4. Parcours pas à pas

A. Le visiteur (sans compte)

  1. Accueil : défiler, cliquer sur Biens.
  2. Filtrer : quartier Bonanjo, budget 400 000 FCFA. Un seul bien ressort : Appartement 3 pièces, résidence Wouri (IB-BNJ-001).
  3. Ouvrir la fiche, cliquer sur Lancer la visite 360° : rotation automatique, boutons Salon, Chambre, Cuisine, Salle de bain.
  4. Menu Simulateur : saisir un revenu net, lire la capacité (règle du tiers).
  5. Ouvrir Awa (bulle en bas à droite) : écrire Un 3 pièces à Bonanjo sous 400 000 FCFA, puis Je gagne 450 000 FCFA par mois. Awa filtre le catalogue à l'écran.
  6. Cliquer sur Réserver : le site demande de se connecter. Passer à l'étape B.

B. Le client : Carine Mbarga

  1. Mon espace → Client. Le tableau de bord montre sa demande RES-2026-0421 en étude juridique, avec le suivi en 6 étapes et 1 pièce manquante (attestation de travail).
  2. Onglets : Mes documents (pièces reçues, manquantes), Messages (échange avec Immo Bell), Notifications, Litiges (LIT-0007 : dépôt de garantie non restitué).
  3. Nouvelle réservation : Biens → Studio meublé centre d'Akwa (IB-AKW-003) → Réserver. Étape 1 : date d'entrée dans le futur, durée. Étape 2 : revenu net 1250000 → « Solvabilité conforme ». Étape 3 : cocher les pièces et accepter la certification. Étape 4 : le code RES-2026-xxxx s'affiche avec des confettis ; Suivre dans mon espace.
  4. Dans Urgences et devis : déclarer une urgence ou demander un devis de déménagement.
Carine a déjà une demande sur IB-BNJ-001 : sur ce bien le bouton affiche « Suivre ma demande ». Pour montrer la réservation, choisir un autre bien libre.

C. L'analyste juridique : Me Ekwalla

  1. Mon espace → Analyste juridique. File d'étude : 4 dossiers avec le temps restant sur les 72 h.
  2. Ouvrir Carine Mbarga (RES-2026-0421) : revenu, solvabilité conforme, liste des pièces. Le bouton Accepter le dossier est grisé tant que toutes les pièces ne sont pas cochées.
  3. Cocher Attestation de travail effective et Dossier du garant solidaire : Accepter le dossier devient actif. Cliquer : le dossier passe dans Dossiers traités, Carine reçoit une notification.
  4. Autres boutons : Demander une pièce (message au client) et Rejeter le dossier (le motif est obligatoire : pièces manquantes, solvabilité insuffisante, garant non conforme, bien déjà attribué…).
  5. Exporter la file (ZIP) télécharge la liste en CSV et une fiche par dossier.

D. Le propriétaire : Mme Ngo Bell

  1. Mon espace → Propriétaire. Mes biens : prix modifiable, disponibilité (libre, réservé, occupé), vues, notes.
  2. Calendrier : bloquer ou débloquer des dates d'un bien saisonnier. Relevés : revenus et commissions selon la formule (Basic 8 %, Standard 12 %, Premium 18 %, Diaspora 18 % + 25 000 FCFA).
  3. Ajouter un bien : titre, type, quartier, prix, pièces, superficie, formule → le bien part « en attente de validation ». Il apparaîtra chez l'administrateur.
  4. Sur un bien validé : Diffuser (texte prêt pour les plateformes partenaires) et Visite 360° (téléverser ses propres photos).

E. Le prestataire : Plomberie du Wouri

  1. Mon espace → Prestataire agréé. Mes interventions : l'urgence URG-0231 (fuite sous l'évier), statut « dispatché ».
  2. Cliquer Je suis en route (le client est prévenu), puis Je suis sur place, écrire le rapport, puis Clôturer avec rapport.
  3. L'intervention passe dans Historique. Demandes de devis : accepter ou refuser, envoyer un montant et un délai. Mon profil : zones, téléphone, tarifs, disponibilité.

F. L'administrateur

  1. Mon espace → Administrateur. Les pastilles rouges indiquent les délais de 72 h qui approchent.
  2. Biens à valider : deux biens du propriétaire. Cliquer Valider sur IB-DDO-011 : il rejoint le catalogue public. Refuser l'autre.
  3. Demandes : filtrer Tous / En cours / Acceptés / Rejetés ; exporter en ZIP (ce dossier, tous les dossiers du locataire, tous ceux du bien).
  4. Urgences : Dispatcher l'urgence URG-0238 (disjoncteur) à un prestataire agréé. Devis : attribuer une demande.
  5. Comptes : suspendre ou réactiver un compte. Journal : toutes les actions horodatées. Rapport : indicateurs et texte du rapport d'activité.
  6. Litiges : prendre en charge, répondre, rendre une décision. Équipe et liste « Agir en tant que » : passer de Super-administrateur à Auditeur (lecture seule) pour montrer les droits.
  7. Feuille V2 : feuille de route classée par priorité (paiement en ligne, signature électronique, états des lieux numériques…).

Questions probables et réponses

  • Ce sont de vraies données ? Non : biens, avis, dossiers et comptes sont des exemples.
  • Les profils sont de vrais comptes ? Non, ce sont des profils de démonstration. Le serveur réel gère de vrais comptes, avec des droits contrôlés côté serveur, mais il n'est pas branché dans cette démonstration.
  • Quand l'ouverture ? Dépend de l'hébergement, des SMS et du paiement Mobile Money ; voir le rapport n° 1.
  • Quelles commissions ? Valeurs du prototype (8, 12, 18 %), base de calcul des packs à arrêter avec l'équipe.
